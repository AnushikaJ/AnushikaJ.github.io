## Problem

The Stall Monitor's box (HC84) did not fit international shipping pallets well, so each unit shipped more air than product, at a higher cost.

## Approach

- Led the redesign from start to finish: material research, supplier negotiation, cardboard mock-ups and drop tests.
- Set the outer dimensions to match international pallet standards so boxes stack without wasted space.

## Result

Package volume fell by **37%** and unit cost by **63.1%**. The new box is now used in production.
